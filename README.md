# Intern Performance Prediction

## Project Overview

This project predicts intern performance based on attendance, task submissions, and feedback using Machine Learning.

The goal is to help mentors identify interns who are likely to succeed and those who may need additional guidance.

## Objective

- Gather intern data
- Analyze attendance, task submissions, and feedback
- Predict intern performance
- Provide insights for mentors

## Tools Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

A synthetic dataset containing 100 intern records was created for educational purposes.

The dataset includes:

- Attendance
- Task Submissions
- Feedback
- Performance

## Machine Learning Model

Decision Tree Classifier

## Visualizations

The notebook contains:

- Attendance Distribution
- Intern Performance Bar Chart
- Feedback vs Task Submission Scatter Plot

## Results

The machine learning model successfully predicted intern performance based on the available data.

## Conclusion

Interns with higher attendance, more task submissions, and better feedback are more likely to perform successfully. These insights can help mentors provide personalized guidance.
